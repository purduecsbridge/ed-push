# Greeter

## Description

Write a class named **`Greeter`** with one method, `greet`, that takes a
name and returns a friendly greeting.

- `greet("Ada")` returns `Hello, Ada!`
- The greeting always ends with an exclamation mark.

## Sample use

```java
Greeter g = new Greeter();
System.out.println(g.greet("Ada"));   // Hello, Ada!
```

## Reference

| Method | What it does |
|--------|--------------|
| `s + t` | joins two Strings |
